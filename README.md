 Logistics Management System - OOP Mini-Project

Overview

This project is a **Logistics Management System** developed as part of an Object-Oriented Programming course. It simulates a network of warehouses, manages product inventories, processes shipments between warehouses, and generates detailed reports.

The system emphasizes **clean architecture**, **interface-based I/O**, and **separation of concerns**, following core OOP principles like encapsulation, composition, and polymorphism.

---

Objective

- Manage multiple warehouses and their inventories
- Load warehouse definitions and inventory data from **files** or **interactive user input**
- Process shipments between warehouses
- Track shipment statistics (successful, partial, failed)
- Generate shipment reports and updated inventory files
- Provide a menu-driven CLI that is robust to invalid input

---

## 🧱 Domain Model (Reused from Quiz)

The following classes are reused from a prior quiz and extended where necessary:

- `Measurement` – measurable quantity with unit, supports adjustment and equality rounding
- `Product` – auto-generated ID, name, and measurement (composition)
- `ProductList` – collection of products with duplicate name merging
- `Warehouse` – manages inventory and shipment lists
- `Adjustable` – interface for adjusting measurements

> ✅ All encapsulation, aggregation behavior, and equality rules are preserved.

---

## 🧩 Architecture

The project is structured into clear layers:

| Layer | Responsibility |
|-------|----------------|
| **Domain** | Core business entities (Product, Warehouse, etc.) |
| **Processing** | Shipment logic, inventory aggregation, reporting |
| **I/O** | Abstract `InputReader` / `OutputWriter` + console/file implementations |
| **Application** | Main class, menu handling, component wiring |

> 🔒 **No direct dependency** between domain layer and concrete I/O classes.
